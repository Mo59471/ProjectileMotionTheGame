## Software Audience 

* The application should be intended for physics teachers and students interested in an alternative way to learn projectile motion and practice regarding solving these types of problems
* A multiplayer mode can also offer the game as a competitive one in which two friends compete to solve physics problems

## First Version Functionality 

* The first version of the game should be in 2d
* The user should be promoted with some projectile motion problem
* The user should be able to solve said problem and test their solution  with visual confirmation 

## Basic User Interaction

* User is prompted with projectile motion problem along with a visual representation
* User solves the problem, and inputs its
* User receives visual conformation and the next problem is displayed until all problems are solved
* An end screen is displayed

## Plans for Later Version

* Ability to play with other people in a competition to solve the projectile motion problems.
* Potential field forces for added complexity

## Research Direction

* Physics in Unity Engine, especially the field forces, (integration or approximations)
